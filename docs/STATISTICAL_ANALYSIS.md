# Statistical Analysis and Evaluation Code

This document explains how the significance tests, confidence intervals, and Wilcoxon signed-rank test in the revised manuscript were computed.

## Input Files

The statistical tests use prediction CSV files generated by the evaluation scripts. Each prediction file must contain at least:

| Column | Meaning |
|---|---|
| `path` | Image path or stable image identifier |
| `true_id` | Ground-truth class id |
| `pred_id` | Top-1 predicted class id |
| `top5_ids` | Semicolon-separated Top-5 predicted class ids |

For paired tests, baseline and full-model files must refer to the same validation images in the same paired order. The script checks both `path` and `true_id`.

## Five-seed Repeated-run Statistical Tests

Script:

```text
eval/compute_significance_stats.py
```

Command:

```bash
python eval/compute_significance_stats.py \
  --eval-root "repaet run eval" \
  --seeds 1,25,42,50,100 \
  --n-boot 2000
```

Curated outputs are stored in:

```text
results/significance/
```

The original generated outputs are also available in:

```text
repaet run eval/significance_stats/
```

### McNemar's Exact Test

McNemar's test compares paired Top-1 correctness between the baseline and the full model on the same images.

For each paired prediction:

- `baseline wrong / full correct` is counted as `b01`.
- `baseline correct / full wrong` is counted as `b10`.
- pairs where both models are correct or both are wrong are not used in the McNemar discordant count.

The exact two-sided test is computed as a binomial test:

```text
n = b01 + b10
p = BinomialTest(min(b01, b10), n, p = 0.5, two-sided)
```

In the revised five-seed analysis:

```text
b01 = 4112
b10 = 3430
p = 4.266e-15
```

### Paired Bootstrap 95% Confidence Intervals

The paired bootstrap estimates confidence intervals for the improvement in:

- Top-1
- Top-5
- Macro-F1
- Weighted-F1

The bootstrap resamples validation image pairs with replacement. For each bootstrap sample, the script computes:

```text
Delta metric = metric(full model) - metric(baseline)
```

The 2.5th and 97.5th percentiles of the bootstrap distribution are reported as the 95% confidence interval.

In the revised five-seed analysis:

| Metric | Delta | 95% CI |
|---|---:|---:|
| Top-1 | 0.651 pp | [0.491, 0.817] |
| Top-5 | 0.022 pp | [-0.047, 0.091] |
| Macro-F1 | 0.285 pp | [0.049, 0.540] |
| Weighted-F1 | 0.597 pp | [0.436, 0.766] |

### Wilcoxon Signed-rank Test for Class-wise Delta F1

For each of the 241 classes, the script computes:

```text
Delta F1_i = F1_i(full model) - F1_i(baseline)
```

For repeated runs, the class-wise Delta F1 values are averaged across the five seeds first. Then a one-sided Wilcoxon signed-rank test is applied:

```text
H0: median class-wise Delta F1 <= 0
H1: median class-wise Delta F1 > 0
```

In the revised five-seed analysis:

```text
mean class Delta F1 = 0.309 pp
positive / negative / zero classes = 129 / 111 / 1
one-sided p = 0.017803
```

## Original Single-run Reviewer Statistics

Script:

```text
eval/analyze_reviewer_stats.py
```

Command:

```bash
python eval/analyze_reviewer_stats.py \
  --baseline results/original_predictions/baseline_predictions.csv \
  --full results/original_predictions/full_predictions.csv \
  --out-dir results/reviewer_stats \
  --n-boot 2000
```

This script produces:

| Output | Purpose |
|---|---|
| `summary_metrics.csv` | Baseline, full model, and delta metrics |
| `paired_tests.json` | McNemar and Wilcoxon test outputs |
| `bootstrap_ci.csv` | Paired bootstrap confidence intervals |
| `all_241_per_class_f1.csv` | Full per-class precision/recall/F1 table |
| `improved_categories.csv` | Categories with positive Delta F1 |
| `degraded_categories.csv` | Categories with negative Delta F1 |
| `confusion_matrix_baseline.csv` | Full baseline confusion matrix |
| `confusion_matrix_full.csv` | Full model confusion matrix |
| `top_confusions_baseline.csv` | Top baseline confusion pairs |
| `top_confusions_full.csv` | Top full-model confusion pairs |

## Which Results Should Be Cited?

Use the five-seed results from `eval/compute_significance_stats.py` for the main response to reviewer concerns about repeated experiments, statistical significance, and confidence intervals.

Use `eval/analyze_reviewer_stats.py` for the original single-run class-level analysis, the complete per-class F1 table, improved/degraded category tables, and full confusion matrices.
