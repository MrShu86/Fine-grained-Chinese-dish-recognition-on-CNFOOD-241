# Results Directory

This directory contains curated result files used to support the revised manuscript and response letter.

| Subdirectory | Contents |
|---|---|
| `repeated_runs/` | Five-seed baseline/full repeated-run tables and per-seed evaluation files |
| `significance/` | McNemar, paired bootstrap, and Wilcoxon outputs |
| `reviewer_stats/` | Original prediction-file statistics, full per-class F1, confusion matrices, improved/degraded categories |
| `transformer_baselines/` | ViT-B/16 and Swin-B metrics, configs, histories, and summary table |
| `ablation/` | Pairwise/core ablation summary |
| `original_predictions/` | Original baseline/full prediction CSV files used for the initial reviewer-statistics analysis |
